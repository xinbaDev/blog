## Blog

### Getting Started


#### Install hugo

```sh
wget https://github.com/gohugoio/hugo/releases/download/v0.79.1/hugo_0.79.1_Linux-64bit.tar.gz
tar -xzvf hugo_0.79.1_Linux-64bit.tar.gz
sudo mv hugo /usr/local/bin/
```

#### Run server

```sh
git clone https://github.com/xinbaDev/blog.git
cd blog

hugo server
```

Then visit http://localhost:1313/posts.
